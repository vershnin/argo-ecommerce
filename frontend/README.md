# Argo Electronics - Frontend

React frontend for the Argo Electronics shop. Modern UI with Tailwind and shadcn/ui components.

## Features
- Shop pages: home, products, cart, checkout, wishlist
- User account, login/register
- Admin dashboard for orders/products
- Smooth animations, mobile friendly

## Tech
- React 18 + TypeScript + Vite
- Zustand for state (auth, cart)
- Axios for API calls to backend
- Tailwind CSS + shadcn/ui

## Run it
1. Node 20+
2. `cd frontend && npm install`
3. `npm run dev` - opens localhost:5173

Proxies API to backend. Ready to browse electronics! 🛒
