# Argo Electronics Ecommerce Shop

Welcome to **Argo Electronics**! Your one-stop online shop for gadgets, electronics, and more.

## About the shop
- Browse cool products with search, filters, categories
- Add to cart, apply coupons, secure checkout
- Track orders, manage wishlist
- Admin panel for store owners
- Built with love: secure login, fast loading, mobile-first design

Full-stack app with Java Spring Boot backend and React frontend. Secure with JWT auth, PostgreSQL DB.

## Get started
- Backend: `cd backend && mvn spring-boot:run` (needs Java/Postgres)
- Frontend: `cd frontend && npm run dev` (needs Node)

Shop at http://localhost:5173. Happy shopping! 🎉
